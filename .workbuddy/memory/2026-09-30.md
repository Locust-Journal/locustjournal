### 关键技术决策与踩坑

**1. Hugo 安装：brew 走不通**
- `brew install hugo` 下载完成但解包阶段被 macOS 嵌套 sandbox 拦（`sandbox_apply: Operation not permitted`），耗时 20 分钟失败
- `dangerouslyDisableSandbox` 与 `HOMEBREW_NO_SANDBOX=1` 都无效（brew 内部自套 sandbox）
- **可行路径**：Hugo 0.167.0 起 macOS 只发 `.pkg` 不发 `.tar.gz`，需 `xar -xf` 解包后再 `gzip -dc Payload | cpio -i` 取出二进制
- 已落位 `/opt/homebrew/bin/hugo`（v0.167.0+extended）
- **教训**：GitHub Release 下载极慢（42MB 用了 23 分钟），必须用 `curl -C - --retry` 断点续传 + 后台任务

**2. Hugo 0.158+ 字段废弃（4 处，已全部覆盖）**
- `languageCode`（项目级）→ `locale`
- `site.Language.LanguageCode` → `site.Language.Locale`
- `.Language.LanguageDirection` → `.Language.Direction`
- `languages.xx.languageName` → `languages.xx.label`
- 覆盖方式：项目根 `layouts/baseof.html`、`layouts/rss.xml`、`layouts/_partials/templates/opengraph.html`
- **教训**：partial 引用路径必须带 `_partials/` 前缀；我凭印象写的 `partial "func/get_image.html"` 根本不存在（该主题无此 partial），必须先 Read 真实文件再改

**3. TOML 语法坑**
- `[[params.assets.customCSS]]` + `= "..."` 写法非法，Hugo 报 `invalid character at start of key: U+003D`
- 正确：`customCSS = ["css/extend/custom.css"]`

**4. 栏目隔离**
- `mainSections = ["articles"]` — 防止学社随笔混进首页文章流
- 卷期页 `hiddenInHomeList: true` — 防止卷期卡片在列表页重复
- 注意：`list: false` 对 section 页不生效，PaperMod 只认 `hiddenInHomeList`

**5. PDF 生成（tools/make_pdf.py，reportlab）**
- macOS 中文字体：PingFang.ttc 需 subfontIndex；STHeiti Medium.ttc 无索引 4；Hiragino 是 PostScript 轮廓 reportlab 不支持
- 最终回退 `/Library/Fonts/Arial Unicode.ttf`，中文显示正常
- 沙箱内 `qlmanage` SVG→PNG 不产出、`cupsfilter` 静默失败，图标改用 Pillow 直接矢量绘制
