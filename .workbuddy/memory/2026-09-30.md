### 关键结论：Cloudflare 面板认错了

用户给的截图是 **Workers** 配置界面（构建命令栏提示 `npx wrangler deploy`），
本项目是纯静态 Hugo 站，**必须走 Workers & Pages → Pages → Connect to Git**。
已在 DEPLOY.md 里加显著警告 + 故障速查表条目。

正确的 Pages 构建设置：
| 字段 | 值 |
|------|-----|
| Framework preset | `Hugo` |
| Build command | `hugo --gc --minify` |
| Build output directory | `public` |
| 环境变量 | `HUGO_VERSION=0.167.0`（必填，CF 不自动推断） |

**Build command 不能加 `--panicOnWarning`** —— 远端 Hugo 版本与本地有细微差异时，
严格模式会因无害 deprecation 直接让整站部署失败。本地把关即可。

### 部署前的验证方法（可复用）

用 `git clone --recurse-submodules` 拉一份干净副本到 /tmp，本地构建后与项目 `public/` 做
`diff -rq` 对比。本次结果**逐字节一致**，证明 submodule 拉取正常、构建可复现、无本地产物污染。

注意：直接 diff 会因 `hugo server` 的 livereload 注入产生大量假差异，
必须先停 server 并跑一次纯净 `hugo --gc --minify` 再比。

### 踩坑
- `git add -A` 会把 submodule 当内嵌仓库报 warning（`adding embedded git repository`），
  需 `git rm --cached -f themes/PaperMod` 后重新 `git submodule add` 注册
- 私有仓 + Cloudflare 需在 GitHub 侧 Settings → Apps 授权，否则 CF 看不到仓库

### 核心判断

根因不是配色，是**缺制度感符号**。博客感来自「卡片流 + 面包屑 + 阅读时长 + 圆角标签药丸」；
期刊感来自「刊名 masthead + 卷期刊号 + 目次 + 篇首 + 摘要框 + 审稿意见书 + 栏目线」。

### Hugo 踩坑（本轮新增）

1. **`.RegularPages` 不递归子 section** —— 稿件在 `content/articles/vol1/` 时，
   `/articles/` 页 `.RegularPages` 长度为 0，目录渲染成空 `<ul>`。
   修：`where site.RegularPages "Section" .Section`
2. **`where` 没有 `Prefix` / `Match` 操作符** —— 只有 `= != in notin intersect`。写错报
   `error calling where: no such operator`
3. **`.Kind` 对词条页是 `"term"` 不是 `"taxonomy"`** —— `"taxonomy"` 是分类总表页
4. **taxonomy 总表模板路径是 `layouts/taxonomy.html`**（顶层），不是 `layouts/_default/terms.html`。
   PaperMod 提供了 `layouts/taxonomy.html`，放错位置会被主题的盖掉
5. **taxonomy 中文刊名不能靠改 config 的单数** —— 改 `tag = "主题词"` 会连 `.Data.Singular`
   一起改掉，导致 `cond (eq .Data.Singular "tag")` 失效。保持英文单数，中文名写在模板里
6. **块内 `{{ $x := }}` 作用域不外传** —— 跨 `if` 复用要在外层 `:=` 声明、块内 `=` 赋值，
   否则报 `undefined variable "$x"`
7. **Hugo 注释不能嵌套 `*/`** —— 跨行注释里再出现 `*/` 会提前闭合，报
   `comment ends before closing delimiter`
8. **`ByWeight` 在无 weight 字段时顺序不确定** —— 曾把蝗掠指数 8.3 排到 7.8 前面。
   改用 `sort ... "Params.seq"`（"01" < "02" 字符串比较有效）
9. **自定义模板必须写 `{{ define "main" }}...{{ end }}`** —— 否则不继承 `baseof.html`，
   输出裸 HTML 片段（无 `<html>`、无 CSS、无 header/footer）
